# SampleApp

Kotlin API with hexagonal architecture and DDD, with Ktor and Gradle, generated by `romanctl`.

```bash
romanctl run sample-app
./gradlew test
```

Address: http://localhost:8081. The `PORT` variable changes the port. `gradlew` downloads Gradle the first time; a
JDK 21 is all it needs.

## Layers

Dependencies always point inward. The Konsist test in `src/test/kotlin/com/example/sampleapp/architecture`
enforces it.

| Package | Contents | Depends on |
|---|---|---|
| `domain` | Aggregates, value objects, events and business rules | only the standard library |
| `application` | Use cases and the ports they need (`OrderRepository`, `EventPublisher`) | domain |
| `adapters` | Port implementations: HTTP with Ktor, persistence and events | application, domain |
| `Application.kt` | Wires the use cases to the adapters and starts the Netty server | all |

The domain and the application know nothing about Ktor.

## Endpoints

| Method | Path | What it does |
|---|---|---|
| `POST` | `/orders` | Creates an order: `{"customerName": "Ana"}` |
| `POST` | `/orders/{id}/items` | Adds an item: `{"productName": "Pen", "quantity": 2, "unitPrice": 3.5}` |
| `POST` | `/orders/{id}/place` | Places the order |
| `GET` | `/orders/{id}` | One order |
| `GET` | `/orders?limit=50` | The most recent orders |
| `GET` | `/health` | API health |

Violated business rules answer 422, orders that do not exist, 404, and invalid bodies, 400, always as
`application/problem+json`.

## Persistence

In memory: the data is gone when the API stops. To use PostgreSQL, generate the project with `--with postgres`.
