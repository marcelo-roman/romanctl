# SampleApp

PHP API with hexagonal architecture and DDD, using Symfony, generated by `romanctl`.

```bash
romanctl run sample-app
composer test
```

Address: http://localhost:8002, served by `php -S 127.0.0.1:8002 -t public`. For another port, change `run` in
`romanctl.yaml`.

## Layers

Dependencies always point inward. The test in `tests/Architecture` enforces this.

| Folder | Contents | Depends on |
|---|---|---|
| `src/Domain` | Aggregates, value objects, events and business rules | PHP only |
| `src/Application` | Use cases and the ports they need (`OrderRepository`, `EventPublisher`, `Clock`) | Domain |
| `src/Adapters` | Port implementations: HTTP, persistence, events and clock | Application, Domain |
| `config/services.yaml` | Binds each port to its implementation | all |

Controllers live in `src/Adapters/Http` and are registered by their `#[Route]` attributes.

## Endpoints

| Method | Path | What it does |
|---|---|---|
| `POST` | `/orders` | Creates an order: `{"customerName": "Ana"}` |
| `POST` | `/orders/{id}/items` | Adds an item: `{"productName": "Pen", "quantity": 2, "unitPrice": 3.5}` |
| `POST` | `/orders/{id}/place` | Places the order |
| `GET` | `/orders/{id}` | One order |
| `GET` | `/orders?limit=50` | The most recent orders, up to 200 |
| `GET` | `/health` | API health |

Violated business rules answer 422, orders that do not exist 404, and invalid bodies 400, always as
`application/problem+json`.

## Persistence

In memory. Since PHP starts every request from scratch, the in-memory repositories keep a copy in
`var/cache/<environment>/memory`, which disappears when the cache is cleared. Nothing is written in tests. To use
PostgreSQL, generate the project with `--with postgres`.
