# SampleApp

Go API with hexagonal architecture and DDD, generated by `romanctl`.

```bash
romanctl run sample-app
go test ./...
```

Address: http://localhost:8090. Change the port with the `PORT` variable.

## Layers

Dependencies always point inward. The test in `internal/architecture` enforces it.

| Folder | Contents | Depends on |
|---|---|---|
| `internal/domain` | Aggregates, value objects, events and business rules | the standard library only |
| `internal/application` | Use cases and the ports they need (`Repository`, `EventPublisher`) | domain |
| `internal/adapters` | Port implementations: HTTP, persistence and events | application, domain |
| `cmd/api` | Wires the adapters and starts the server | all |

## Endpoints

| Method | Path | What it does |
|---|---|---|
| `POST` | `/orders` | Creates an order: `{"customerName": "Ana"}` |
| `POST` | `/orders/{id}/items` | Adds an item: `{"productName": "Pen", "quantity": 2, "unitPrice": 3.5}` |
| `POST` | `/orders/{id}/place` | Places the order |
| `GET` | `/orders/{id}` | One order |
| `GET` | `/orders?limit=50` | The most recent orders |
| `GET` | `/health` | API health |

Business rule violations answer 422, and orders that do not exist, 404.

## Persistence

In memory: the data is gone when the API stops. To use PostgreSQL, generate the project with `--with postgres`.
