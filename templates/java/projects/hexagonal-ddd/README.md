# SampleApp

Java API with hexagonal architecture and DDD, with Spring Boot and Maven, generated by `romanctl`.

```bash
romanctl run sample-app
mvn test
```

Address: http://localhost:8080. The `PORT` variable changes the port.

## Layers

Dependencies always point inward. The ArchUnit test in `src/test/java/com/example/sampleapp/architecture`
enforces it.

| Package | Contents | Depends on |
|---|---|---|
| `domain` | Aggregates, value objects, events and business rules | only the JDK |
| `application` | Use cases and the ports they need (`OrderRepository`, `EventPublisher`) | domain |
| `adapters` | Port implementations: HTTP, persistence and events | application, domain, Spring |
| `config` | Wires the use cases to the adapters | all |

The domain and the application know nothing about Spring. The adapters are found by component scan, and the use cases
become beans in the `config` classes.

## Endpoints

| Method | Path | What it does |
|---|---|---|
| `POST` | `/orders` | Creates an order: `{"customerName": "Ana"}` |
| `POST` | `/orders/{id}/items` | Adds an item: `{"productName": "Pen", "quantity": 2, "unitPrice": 3.5}` |
| `POST` | `/orders/{id}/place` | Places the order |
| `GET` | `/orders/{id}` | One order |
| `GET` | `/orders?limit=50` | The most recent orders |
| `GET` | `/health` | API health |

Violated business rules answer 422, orders that do not exist, 404, and invalid bodies, 400, always as
`application/problem+json`.

## Persistence

PostgreSQL with `JdbcClient`, read from `SPRING_DATASOURCE_URL`, `SPRING_DATASOURCE_USERNAME` and
`SPRING_DATASOURCE_PASSWORD`. `romanctl up sample-app` creates the `sample_app` database and writes these variables to `.env`.
The tables in `src/main/resources/schema.sql` are created at startup with `CREATE TABLE IF NOT EXISTS`, which does not
evolve the schema: adopt migrations, such as Flyway, before you have data that matters.

The repository test only runs with `DATABASE_URL` set; without it, it is marked as skipped.

`app.persistence=memory` swaps PostgreSQL for the in-memory repositories, as the HTTP tests do.
