# SampleApp

Full-stack monorepo with Next.js and tRPC, in TypeScript, generated by `romanctl`.

```bash
romanctl run sample-app
npm test
```

Address: http://localhost:3200. The port changes with the `PORT` variable.

| Script | What it does |
|---|---|
| `npm run dev` | Starts Next.js in development mode, with the tRPC API at `/api/trpc` |
| `npm test` | Checks the types and runs the tests of every package with Vitest |
| `npm run build` | Builds Next.js for production, with `output: "standalone"` |
| `npm start` | Starts the production build |

## Packages

A single process: Next.js serves the pages and the tRPC API, through a route handler in
`apps/web/src/app/api/trpc/[trpc]/route.ts`. The test in `tests/architecture.test.ts` enforces the direction of the
dependencies.

| Folder | Contents | Depends on |
|---|---|---|
| `packages/db` | Repository interfaces, with plain records, and the implementation in `memory/` | nothing |
| `packages/api` | Domain (`Order`, `Money`), services with the rules and the tRPC router with zod validation | the `db` interfaces, only through `import type` |
| `apps/web` | Next.js (App Router), React and TanStack Query with `@trpc/tanstack-react-query` | the `AppRouter` type and the tRPC client |

In `apps/web`, only `src/server` and the route handler import values from `@sample-app/api` and choose the repositories.
The components know the API only through the `AppRouter` type, via the tRPC client. The domain in `packages/api` does
not depend on anything outside it, and `packages/api` knows nothing about Next.js or React.

## Procedures

| Procedure | Type | What it does |
|---|---|---|
| `orders.create` | mutation | Creates an order: `{ customerName: "Ana" }` |
| `orders.addItem` | mutation | Adds an item: `{ orderId, productName: "Pen", quantity: 2, unitPrice: 3.5, currency: "USD" }` |
| `orders.place` | mutation | Places the order: `{ orderId }` |
| `orders.byId` | query | One order: `{ orderId }` |
| `orders.list` | query | The most recent orders; `limit` defaults to 50 and is at most 200 |

```bash
curl 'http://localhost:3200/api/trpc/orders.list'
```

## Rules

- The customer name and the product name are required.
- The quantity is a whole number greater than zero; the price cannot be negative; the default currency is USD.
- All items of an order use the same currency.
- Only a draft order with at least one item can be placed; after that, it no longer changes.

| tRPC code | HTTP | When |
|---|---|---|
| `BAD_REQUEST` | 400 | Input rejected by zod; `data.issues` carries the messages |
| `UNPROCESSABLE_CONTENT` | 422 | Business rule violated, such as different currencies or an order without items |
| `PRECONDITION_FAILED` | 412 | Order already placed |
| `NOT_FOUND` | 404 | Order that does not exist |

The screen shows the message for each case, through `apps/web/src/lib/error-message.ts`.

## Persistence

In memory: the data is gone when Next.js stops. To use PostgreSQL, generate the project with `--with postgres`.
