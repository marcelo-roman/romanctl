# SampleApp

.NET API with Clean Architecture, DDD and CQRS, generated by `romanctl`.

```bash
romanctl run sample-app
dotnet test
```

Address: http://localhost:5080. OpenAPI document: `/openapi/v1.json`.

## Layers

Dependencies always point inward. A test in `ArchitectureTests` enforces it.

| Project | Contents | Depends on |
|---|---|---|
| `SampleApp.Domain` | Aggregates, value objects, events and business rules | nothing |
| `SampleApp.Application` | Commands, queries and handlers | Domain |
| `SampleApp.Infrastructure` | Persistence | Application |
| `SampleApp.Api` | HTTP endpoints | Application, Infrastructure |

## CQRS

Commands change state through the aggregate repository. Queries read through `IOrderReadStore` and
return DTOs. `IDispatcher` finds each message's handler through dependency injection.

## Persistence

In memory: the data is gone when the API stops. To use PostgreSQL, generate the project with
`--with postgres`.
