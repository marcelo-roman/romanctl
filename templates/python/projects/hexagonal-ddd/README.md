# SampleApp

Python API with hexagonal architecture and DDD, using FastAPI and uv, generated by `romanctl`.

```bash
romanctl run sample-app
uv run pytest
uv run ruff check
```

Address: http://localhost:8000. The `PORT` variable changes the port, and the interactive documentation is at `/docs`.

## Layers

Dependencies always point inward. The test in `tests/architecture` enforces it.

| Folder | Contents | Depends on |
|---|---|---|
| `src/sample_app/domain` | Aggregates, value objects, events and business rules | only the standard library |
| `src/sample_app/application` | Use cases and the ports they need (`OrderRepository`, `EventPublisher`) | domain |
| `src/sample_app/adapters` | Port implementations: HTTP, persistence and events | application, domain |
| `src/sample_app/bootstrap.py` | Wires the adapters and the FastAPI application | all |

## Endpoints

| Method | Path | What it does |
|---|---|---|
| `POST` | `/orders` | Creates an order: `{"customerName": "Ana"}` |
| `POST` | `/orders/{id}/items` | Adds an item: `{"productName": "Pen", "quantity": 2, "unitPrice": 3.5}` |
| `POST` | `/orders/{id}/place` | Places the order |
| `GET` | `/orders/{id}` | One order |
| `GET` | `/orders?limit=50` | The most recent orders |
| `GET` | `/health` | API health |

Violated business rules respond 422, orders that do not exist 404, and invalid bodies 400, always as
`application/problem+json`.

## Persistence

PostgreSQL with psycopg 3, read from `DATABASE_URL`. `romanctl up sample-app` creates the `sample_app` database and
writes the variable to `.env`. Tables are created on startup with `CREATE TABLE IF NOT EXISTS`, which does not evolve
the schema: adopt migrations before you have data that matters. The tests in `tests/postgres` only run when
`DATABASE_URL` is set.
