# SampleApp

Layered Python API with Django, Django REST Framework and uv, generated by `romanctl`.

```bash
romanctl run sample-app        # applies the migrations and starts the server
uv run pytest
uv run ruff check
uv run python manage.py makemigrations
```

Address: http://localhost:8001. The `PORT` variable changes the port. `uv run sample-app` runs `migrate` and then
`runserver`, and `manage.py` covers the rest.

## Layers

Each Django app is split into layers, and dependencies always go down: views → services and selectors → models. The
test in `tests/test_layers.py` enforces it, and also that views do not use the ORM directly.

| File | Contents | Depends on |
|---|---|---|
| `tasks/models.py` | Django models | nothing in the project |
| `tasks/selectors.py` | Queries | models |
| `tasks/services.py` | Business rules and writes | models, selectors |
| `tasks/serializers.py` | Input validation and output format | models |
| `tasks/views.py` | Thin DRF views: they validate, call services or selectors and respond | serializers, services, selectors |
| `tasks/urls.py` | App routes | views |
| `sample_app/` | Settings, root URLs, WSGI/ASGI and the error handler | |

## Endpoints

The JSON uses snake_case, like the model fields.

| Method | Path | What it does |
|---|---|---|
| `POST` | `/tasks` | Creates a task: `{"title": "Buy bread", "due_date": "2030-01-31"}` |
| `GET` | `/tasks?done=false&limit=50` | The most recent tasks; `limit` goes from 1 to 200, 50 by default |
| `GET` | `/tasks/{id}` | One task |
| `PATCH` | `/tasks/{id}` | Changes `title`, `done` or `due_date` |
| `DELETE` | `/tasks/{id}` | Removes the task |
| `GET` | `/health` | API health |

A task has `id`, `title` (required, up to 200 characters, no leading or trailing spaces), `done`, `due_date`
(optional, never in the past when creating or changing the due date) and `created_at`.

Invalid bodies respond 400, tasks that do not exist 404, and violated business rules 422, always as
`application/problem+json`: `{"status": 422, "title": "Business rule violated", "detail": "..."}`.
Routes that do not exist also respond this way, except with `DJANGO_DEBUG=true`, the default in development, where
Django shows its debug page.

## Persistence

SQLite in `db.sqlite3`, in the project folder and out of git. The `SQLITE_PATH` variable changes the path. To switch
to PostgreSQL, generate the project with `--with postgres`.

Tables come from the Django migrations, in `tasks/migrations`. When you change a model, run
`uv run python manage.py makemigrations` and commit the generated file. Tests run on in-memory SQLite.

## Production

`DJANGO_DEBUG=false` requires `DJANGO_SECRET_KEY`. `DJANGO_ALLOWED_HOSTS` takes the domains separated by commas.
