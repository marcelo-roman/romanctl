# SampleApp

Rust API with hexagonal architecture and DDD, generated by `romanctl`.

```bash
romanctl run sample-app
cargo test
cargo clippy --all-targets -- -D warnings
```

Address: http://localhost:3100. The port changes with the `PORT` variable.

## Layers

Dependencies always point inward. The test in `tests/architecture.rs` enforces this.

| Folder | Contents | Depends on |
|---|---|---|
| `src/domain` | Aggregates, value objects, events and business rules | `chrono`, `thiserror`, `uuid` |
| `src/application` | Use cases and the ports they need (`OrderRepository`, `EventPublisher`) | domain |
| `src/adapters` | Port implementations: HTTP with axum, persistence and events | application, domain |
| `src/bootstrap.rs` | Wires the adapters into each use case | all |
| `src/main.rs` | Reads the environment and starts the server | bootstrap |

## Endpoints

| Method | Path | What it does |
|---|---|---|
| `POST` | `/orders` | Creates an order: `{"customerName": "Ana"}` |
| `POST` | `/orders/{id}/items` | Adds an item: `{"productName": "Pen", "quantity": 2, "unitPrice": 3.5}` |
| `POST` | `/orders/{id}/place` | Places the order |
| `GET` | `/orders/{id}` | One order |
| `GET` | `/orders?limit=50` | The most recent orders, up to 200 |
| `GET` | `/health` | API health |

Violated business rules answer 422, orders that do not exist 404, and invalid bodies 400.

## Persistence

In memory: the data disappears when the API stops. To use PostgreSQL, generate the project with `--with postgres`.
